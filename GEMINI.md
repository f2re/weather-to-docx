# Инструкции Gemini CLI

Перед планированием или изменением репозитория обязательно прочитайте:

1. `AGENTS.md`;
2. `docs/DEVELOPMENT_CONTRACT.md`;
3. относящиеся к задаче тесты и документацию.

Эти документы являются обязательными. Этот файл только подключает Gemini CLI к общему контракту и не содержит альтернативных правил.

Критические требования:

- получить актуальную `main` и её SHA до первого изменения;
- читать текущую версию из `pyproject.toml`;
- не понижать и не менять версию без явной подготовки выпуска;
- не путать ожидаемый релизный маркер, Git-тег и GitHub Release;
- не сообщать о зелёном CI, слиянии или релизе без свежего результата;
- добавлять тест на новое поведение и регрессионный тест на исправление;
- не сливать PR с незавершёнными проверками;
- после слияния повторно проверить `main`, версию и merge SHA.

Минимальный gate:

```bash
python scripts/check-version.py
python scripts/check-development-contract.py
make agent-check
```
