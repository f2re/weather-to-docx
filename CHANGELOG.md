# История изменений

## 0.2.0 — 2026-08-03

### Добавлено

- отдельные детерминированные адаптеры NOAA GFS, ECMWF IFS, ECMWF AIFS, DWD ICON Global и ECCC GEM/GDPS через Open-Meteo;
- ансамблевые адаптеры NOAA GEFS 0.25°/0.5°, ECMWF IFS ENS, ECMWF AIFS ENS, DWD ICON EPS и ECCC GEPS;
- расчёт среднего, стандартного отклонения, 10-го и 90-го процентилей по доступным членам ансамбля;
- расчёт вероятности осадков по настраиваемому порогу и фактическому числу членов;
- круговое усреднение направления ветра;
- сохранение идентификатора исходной модели и службы доставки данных;
- вывод ансамблевых статистик, изобарических уровней и остальных доступных полей во второй таблице DOCX;
- постоянный справочник координат SQLite с группами, импортом и экспортом;
- локальный адаптивный интерфейс оператора без CDN и внешних ресурсов;
- выбор нескольких точек и моделей, настройка горизонта, запуск, отмена и повтор заданий;
- скачивание DOCX, ZIP и манифестов из интерфейса;
- проверка включения статических файлов интерфейса в wheel;
- CI-проверка JavaScript, shell-сценариев и сборки автономного комплекта.

### Изменено

- версия приложения и HTTP User-Agent обновлены до `0.2.0`;
- генератор DOCX подписывает исходную модель, продукт, способ доставки и число членов ансамбля;
- пример конфигурации расширен до многомодельного прогноза;
- README полностью актуализирован для интерфейса, ансамблей и автономной установки;
- максимальное число координат одного задания увеличено до 1000;
- детерминированная сумма осадков больше нигде не трактуется как вероятность.

### Исправлено

- устранён конфликт статического маршрута экспорта координат с маршрутом одной точки;
- исключена некорректная схема ответа FastAPI для корневой страницы интерфейса;
- дополнительные параметры модели больше не теряются при формировании DOCX;
- разные прогностические модели не объединяются через автоматический `best_match`.

## 0.1.0 — 2026-08-03

### Добавлено

- единая модель прогноза и признаков качества;
- источник NOAA GFS через Open-Meteo;
- прямой загрузчик GFS 0.25° NOAA NOMADS;
- автономный демонстрационный источник;
- пакетная генерация отдельного DOCX по каждой координате;
- наглядная и подробная таблицы для каждой модели;
- локальные PNG-пиктограммы и правила погодных явлений;
- манифесты, SHA-256 и ZIP результатов;
- SQLite WAL очередь, worker и FastAPI;
- подписанные Ed25519 прогнозные пакеты `.tar.zst`;
- сценарии сборки, установки, обновления и отката для Astra Linux;
- systemd-службы, CI и эксплуатационная документация.
