# Инструкции Claude Code

Перед планированием или изменением репозитория обязательно прочитайте:

1. `AGENTS.md`;
2. `docs/DEVELOPMENT_CONTRACT.md`;
3. относящиеся к задаче тесты и документацию.

Эти документы являются обязательными. Этот файл не создаёт отдельный набор правил и не может их ослаблять.

Критические требования:

- начинать работу от актуальной `main` и фиксировать её SHA;
- читать версию из `pyproject.toml`, не по памяти;
- не уменьшать и не менять версию без явной задачи на выпуск;
- различать файловый маркер, реальный Git-тег и GitHub Release;
- не заявлять о тестах, CI, слиянии или релизе без фактической проверки;
- создавать регрессионный тест для исправленного дефекта;
- держать PR в draft до полного зелёного CI;
- после слияния повторно проверить `main`, версию и merge SHA.

Минимальный gate:

```bash
python scripts/check-version.py
python scripts/check-development-contract.py
make agent-check
```
