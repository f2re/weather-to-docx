# Состояние выпуска

Текущая версия исходного кода: **0.5.1**.

## Эксплуатационный статус

**Эксплуатационная приёмка версии 0.5.1 завершена 2026-08-06. Этап 0.5.x закрыт.**

Результат зафиксирован в [`ACCEPTANCE_RESULT_0.5.1.md`](ACCEPTANCE_RESULT_0.5.1.md). Основанием является подтверждение владельца проекта о прохождении эксплуатационной приёмки. Детализированный внешний протокол целевой площадки в репозиторий не приложен.

Закрытие приёмки не изменяет номер версии: новых функций или исправлений кода в рамках этого решения не выпускалось. Следующий активный этап — **0.6.0**, архив нормализованных циклов и честное сравнение изменений прогноза. План находится в [`ROADMAP.md`](ROADMAP.md).

## Согласованность версии

Согласованные источники версии:

- `pyproject.toml`;
- `VERSION`;
- `weather_to_docx.__version__`;
- метаданные адаптеров;
- User-Agent в эталонных конфигурациях;
- README и документы текущего выпуска;
- маркеры `docs/.release-ready` и `docs/RELEASE_TAG.txt`.

CI выполняет `scripts/check-version.py` и блокирует слияние при любом расхождении. Исторические разделы `CHANGELOG.md` и файл `RELEASE_0.3.0.md` не являются указателями текущей версии.

Ожидаемый тег выпуска: `v0.5.1`. Публикация Git-тега и GitHub Release выполняется отдельно от изменения исходного кода. Факт эксплуатационной приёмки не означает автоматического создания тега или GitHub Release.
