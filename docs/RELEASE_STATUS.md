# Состояние выпуска

Текущая версия исходного кода: **0.5.1**.

Согласованные источники версии:

- `pyproject.toml`;
- `VERSION`;
- `weather_to_docx.__version__`;
- метаданные адаптеров;
- User-Agent в эталонных конфигурациях;
- README и документы текущего выпуска;
- маркеры `docs/.release-ready` и `docs/RELEASE_TAG.txt`.

CI выполняет `scripts/check-version.py` и блокирует слияние при любом расхождении. Исторические разделы `CHANGELOG.md` и файл `RELEASE_0.3.0.md` не являются указателями текущей версии.

Ожидаемый тег выпуска: `v0.5.1`. Публикация Git-тега и GitHub Release выполняется отдельно от изменения исходного кода.
