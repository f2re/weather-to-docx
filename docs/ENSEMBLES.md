# 🎯 Ансамблевые прогнозы

## Назначение

Ансамбль описывает не единственный сценарий, а распределение возможных состояний атмосферы. В `weather-to-docx` ансамблевые системы не маскируются под обычные модели и выводятся отдельным завершающим разделом документа.

Порядок DOCX:

```text
Детерминированная модель 1
├── наглядная таблица
└── подробная таблица

Детерминированная модель 2
├── наглядная таблица
└── подробная таблица

Ансамблевая оценка неопределённости
└── одна сравнительная таблица всех выбранных ансамблевых систем
```

Члены GEFS, ECMWF ENS, AIFS ENS, ICON-EPS и GEPS не объединяются между собой. У систем различаются модели, циклы, возмущения, разрешение, число членов и статистические свойства. Простое межмодельное объединение без верификации создало бы продукт с неясным вероятностным смыслом.

## Принятые научные правила

### Равные веса

Внутри одной ансамблевой системы доступные члены считаются равновероятными:

```text
wᵢ = 1 / N
```

Система не присваивает отдельным членам субъективные веса и не удаляет «неудобные» сценарии.

### Температура и давление

Для величин с обычно близким к симметричному распределением основной центр — среднее:

```text
x̄ = (1 / N) × Σ xᵢ
```

Spread рассчитывается как стандартное отклонение членов относительно среднего:

```text
σ = √[(1 / N) × Σ(xᵢ − x̄)²]
```

В таблице дополнительно приводится `q10–q90`.

### Осадки, ветер и другие асимметричные величины

Для неотрицательных, ограниченных или выраженно асимметричных распределений основной центр — медиана `q50`.

Это применяется к:

- осадкам;
- дождю, ливням и снегу;
- скорости и порывам ветра;
- CAPE и CIN;
- облачности;
- относительной влажности.

Диапазон `q10–q90` содержит центральные 80 % членов и менее чувствителен к единичным крайним значениям, чем полный минимум–максимум.

### Квантили

Используется оценка Hyndman–Fan type 8, рекомендуемая как приблизительно несмещённая по медиане независимо от формы непрерывного распределения.

Для упорядоченной выборки и вероятности `p`:

```text
h = (N + 1/3) × p + 1/3
```

Значение интерполируется между соседними порядковыми статистиками. Метод фиксирован в коде и покрыт эталонными тестами.

### Направление ветра

Обычное арифметическое среднее направлений применять нельзя: среднее между 350° и 10° должно находиться около 0°, а не 180°.

Используется круговое среднее:

```text
u = mean(cos θᵢ)
v = mean(sin θᵢ)
θ̄ = atan2(v, u)
```

### Вероятность превышения порога

Сырая вероятность события рассчитывается только по доступным членам одной системы:

```text
Praw = 100 × M / N
```

где:

- `M` — число членов с величиной не ниже порога;
- `N` — число доступных членов для этого срока.

Для осадков по умолчанию используются пороги:

```text
0.1 мм
1.0 мм
5.0 мм
```

Пороги можно изменить в интерфейсе, API или конфигурации Telegram.

### Дискретность вероятности

Ансамбль не способен выдавать вероятность с произвольной точностью. Минимальный шаг сырой вероятности:

```text
ΔP = 100 / N процентных пунктов
```

Например, при 31 члене шаг составляет примерно 3.23 п.п. Значения не следует интерпретировать точнее этого шага.

### Неполный ансамбль

Для каждого срока сохраняются:

- число доступных членов;
- ожидаемое число членов, когда оно надёжно известно;
- полнота в процентах;
- признак качества.

Если часть членов отсутствует, значение помечается как сомнительное. Система не дополняет отсутствующие члены нулями и не пересчитывает их из соседних сроков.

## Почему вероятность называется сырой

Доля членов `M/N` является прямой модельной вероятностью. Она может быть систематически смещена, если:

- модель имеет смещение;
- ансамбль недодисперсионный или передисперсионный;
- наблюдение не соответствует масштабу модельной ячейки;
- порог или интервал накопления выбраны неудачно;
- локальный рельеф не разрешён моделью.

Поэтому в документе используется формулировка:

> сырая некалиброванная вероятность

Система не выдаёт её за локально проверенную вероятность.

## Что намеренно не рассчитывается без архива наблюдений

Следующие продукты требуют сопоставленного архива прогнозов, наблюдений и, желательно, ретропрогнозов:

- reliability diagram;
- Brier Score и Brier Skill Score;
- CRPS и CRPSS;
- ROC/AUC;
- rank histogram;
- spread–skill relationship;
- EMOS и Bayesian Model Averaging;
- локальная калибровка вероятностей;
- нормирование spread относительно климатологии модели.

До появления такого архива эти показатели не имитируются приближёнными формулами.

## Интерпретация таблицы

### Температура

```text
18.2 ± 1.4 °C
[15.9; 20.6]
```

означает:

- среднее членов: 18.2 °C;
- стандартное отклонение: 1.4 °C;
- q10: 15.9 °C;
- q90: 20.6 °C.

Это не означает, что реальное значение гарантированно попадёт в диапазон.

### Осадки

```text
q50 0.8 мм
[0.0; 6.2]
```

означает медиану 0.8 мм и центральные 80 % членов от 0 до 6.2 мм. Распределение может быть сильно асимметричным.

### Вероятность

```text
≥1 мм: 42 %
```

при 31 доступном члене означает 13 из 31 членов. Это не калиброванная вероятность наблюдаемого осадка в точном месте.

## Реализация

Научные операции находятся в:

```text
src/weather_to_docx/ensemble/science.py
```

Нормализация ансамблевых данных:

```text
src/weather_to_docx/sources/open_meteo_ensemble.py
```

```text
src/weather_to_docx/document/scientific_generator.py
```

```text
tests/test_ensemble_science.py
tests/test_open_meteo_models.py
tests/test_scientific_document.py
```
