# 🎯 Ансамблевые прогнозы

## Назначение

Ансамбль описывает распределение возможных состояний атмосферы, а не один сценарий. В `weather-to-docx` ансамблевые системы не маскируются под обычные модели и выводятся отдельным завершающим разделом.

```text
Детерминированная модель 1
├── наглядная таблица
└── подробная таблица

Детерминированная модель 2
├── наглядная таблица
└── подробная таблица

Ансамблевая оценка неопределённости
└── одна сравнительная таблица выбранных ансамблевых систем
```

Члены GEFS, ECMWF ENS, AIFS ENS, ICON-EPS и GEPS не объединяются между собой. У систем различаются модели, возмущения, разрешение, число членов и статистические свойства. Простое объединение без верификации создало бы продукт с неясным вероятностным смыслом.

## 1. Равные веса членов

Внутри одной ансамблевой системы все доступные члены считаются равновероятными:

```text
wᵢ = 1 / N
```

Система не назначает субъективные веса и не удаляет отдельные сценарии по величине результата.

## 2. Температура и давление

Для величин с обычно близким к симметричному распределением основной центр — среднее:

```text
x̄ = (1 / N) × Σxᵢ
```

Spread рассчитывается как стандартное отклонение членов относительно среднего:

```text
σ = √[(1 / N) × Σ(xᵢ − x̄)²]
```

В таблице дополнительно приводится диапазон `q10–q90`.

## 3. Осадки, ветер и асимметричные величины

Для неотрицательных, ограниченных или выраженно асимметричных распределений основной центр — медиана `q50`.

Это применяется к:

- осадкам;
- дождю, ливням и снегу;
- скорости и порывам ветра;
- CAPE и CIN;
- облачности;
- относительной влажности.

Диапазон `q10–q90` содержит центральные 80 % членов и менее чувствителен к единичным крайним значениям, чем полный минимум–максимум.

## 4. Квантили

Используется оценка Hyndman–Fan type 8. Для упорядоченной выборки и вероятности `p`:

```text
h = (N + 1/3) × p + 1/3
```

Значение интерполируется между соседними порядковыми статистиками. Метод фиксирован в коде и покрыт эталонными тестами.

## 5. Направление ветра

Арифметическое среднее углов применять нельзя: среднее между 350° и 10° должно находиться около 0°, а не 180°.

Используются средние компоненты единичных векторов:

```text
u = mean(cos θᵢ)
v = mean(sin θᵢ)
R = √(u² + v²)
θ̄ = atan2(v, u)
```

`R` характеризует согласованность направлений:

- `R≈1` — члены показывают близкие направления;
- `R≈0` — направления взаимно компенсируются.

При `R≈0` среднее направление физически не определено. Система возвращает пустое сомнительное значение и предупреждение, а не направление первого члена.

## 6. Вероятность превышения порога

Сырая вероятность события рассчитывается по доступным членам одной системы:

```text
Praw = 100 × M / N
```

где:

- `M` — число членов, достигших или превысивших порог;
- `N` — число членов, для которых доступен именно этот параметр и срок.

Для осадков по умолчанию используются пороги:

```text
0.1 мм
1.0 мм
5.0 мм
```

Каждая вероятностная ячейка содержит полное событие:

```text
≥1 мм за 3 ч: 42 % (13/31)
```

То есть оператор видит:

- порог;
- период накопления;
- процент;
- число сработавших членов `M`;
- число доступных членов `N`.

Общее число членов строки не подменяет `N` конкретного события.

## 7. Дискретность вероятности

Минимальный шаг сырой вероятности:

```text
ΔP = 100 / N процентных пунктов
```

Например, при 31 члене шаг составляет примерно 3.23 п.п. Значение нельзя интерпретировать точнее этого шага.

## 8. Интервал накопления

Порог осадков не имеет смысла без периода. Адаптер сохраняет:

```text
source_start_step
source_end_step
accumulation_hours
```

Для агрегированной выдачи период определяется по фактическому временному шагу ответа. Если поставщик не сообщил период однозначно, документ использует формулировку «за интервал источника», а не придумывает часовую сумму.

## 9. Неполный ансамбль

Для каждого срока сохраняются:

- минимальное число членов по отображаемым полям;
- ожидаемое число членов, когда оно известно;
- полнота в процентах;
- признак качества;
- отдельный `N` каждого вероятностного события.

Если часть членов отсутствует, значение помечается как сомнительное. Отсутствующие члены не заменяются нулями и не восстанавливаются из соседних сроков.

## 10. Шкала заблаговременности

Истинная заблаговременность определяется только при известном времени цикла:

```text
lead = valid_time − cycle_time
```

Для прямого NOAA GFS документ пишет:

```text
+24 ч от цикла
```

Стандартный ответ Open-Meteo не содержит надёжного времени исходного цикла. Для таких рядов смещение рассчитывается от первого срока полученной выдачи и подписывается:

```text
+24 ч от начала выдачи
```

Эти две шкалы нельзя смешивать.

## 11. Почему вероятность называется сырой

Доля `M/N` может быть систематически смещена, если:

- модель имеет смещение;
- ансамбль недодисперсионный или передисперсионный;
- наблюдение не соответствует масштабу модельной ячейки;
- локальный рельеф не разрешён моделью;
- порог или период накопления выбраны неудачно.

Поэтому в документе используется формулировка:

> сырая некалиброванная вероятность

Система не выдаёт её за локально проверенную вероятность.

## 12. Что не рассчитывается без архива наблюдений

Следующие продукты требуют сопоставленного архива прогнозов, наблюдений и, желательно, ретропрогнозов:

- reliability diagram;
- Brier Score и Brier Skill Score;
- CRPS и CRPSS;
- ROC/AUC;
- rank histogram;
- spread–skill relationship;
- EMOS;
- Bayesian Model Averaging;
- локальная калибровка вероятностей;
- нормирование spread относительно климатологии модели.

До появления такого архива эти показатели не имитируются приближёнными формулами.

## 13. Интерпретация таблицы

### Температура

```text
18.2 ± 1.4 °C
[15.9; 20.6]
```

означает:

- среднее членов — 18.2 °C;
- стандартное отклонение — 1.4 °C;
- q10 — 15.9 °C;
- q90 — 20.6 °C.

Диапазон не является гарантированным доверительным интервалом наблюдения.

### Осадки

```text
0.8 мм
[0.0; 6.2]
```

означает медиану 0.8 мм и центральные 80 % членов от 0 до 6.2 мм.

### Вероятность

```text
≥1 мм за 3 ч: 42 % (13/31)
```

означает, что 13 из 31 доступного члена дали не менее 1 мм за указанный трёхчасовой интервал.
