# Weather to DOCX 0.3.0

Выпуск переводит ансамблевые прогнозы в отдельную научную секцию документа и добавляет минимальные точки входа для оператора.

## Основное

- детерминированные модели выводятся первыми, по две таблицы на модель;
- выбранные ансамблевые системы сравниваются в одной отдельной таблице в конце;
- равные веса членов одной системы;
- среднее и стандартное отклонение для температуры и давления;
- медиана и q10–q90 для асимметричных величин;
- квантили Hyndman–Fan type 8;
- круговое среднее направления ветра;
- сырые M/N-вероятности по нескольким порогам;
- число членов, полнота и дискретность 100/N;
- DaData suggest, clean и reverse;
- Telegram-бот: город, адрес, координаты, геопозиция, TXT, CSV и JSON;
- DOCX для одной точки и ZIP для нескольких;
- минималистичный трёхшаговый веб-интерфейс;
- `setup.sh` и интерактивный мастер токенов;
- совместимый откат на версии 0.2.x;
- офлайн-комплект Astra Linux с wheelhouse, systemd и SBOM.

## Проверка

- Python 3.11, 3.12 и 3.13;
- Ruff;
- автономные тесты ансамблевой статистики, DOCX, DaData, Telegram и упаковки;
- проверка JavaScript и shell;
- сборка wheel;
- формирование тестового DOCX;
- сборка и проверка офлайн-комплекта.

Производственный архив Astra Linux необходимо собирать в среде, совместимой с целевой системой по архитектуре, glibc, Python и системным репозиториям.
