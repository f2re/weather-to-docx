# Текущий выпуск: Weather to DOCX 0.5.1

Версия 0.5.1 развивает профессиональные метеограммы и оперативную интерпретацию прогноза:

- осадки нормализуются к интенсивности `мм/ч` с общей шкалой;
- температура, ветер и давление используют сопоставимые смысловые диапазоны;
- отмечаются переходы через 0 °C, сильные и опасные порывы, грозы, морось и вероятный туман;
- ансамблевые графики показывают диапазоны 25–75 и 10–90 процентов;
- документ проходит структурную и физическую проверку через LibreOffice/Poppler;
- текущая версия автоматически сверяется между кодом, конфигурациями и документацией.
