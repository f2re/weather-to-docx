# Weather to DOCX 0.5.1

Текущий выпуск объединяет профессиональные метеограммы, оперативную интерпретацию рисков и сопоставимые смысловые шкалы.

## Основное

- три режима документа: краткий, экспертный и полный;
- отдельная полноразмерная метеограмма каждой пригодной модели;
- отдельная ансамблевая метеограмма с диапазонами 25–75 и 10–90 процентов;
- ключевые риски с временным окном, максимумом, поддержкой моделей и ансамблевой вероятностью;
- русские подписи, местное время, ночные интервалы и контроль свежести данных;
- структурная и физическая проверка DOCX через LibreOffice и Poppler.

## Смысловые шкалы

- осадки нормализуются к `мм/ч` и используют общую шкалу до 12 мм/ч;
- значения выше шкалы сохраняют фактическую подпись;
- температура использует диапазон не уже −20…+40 °C;
- ветер использует диапазон не уже 0…25 м/с с порогами 14 и 20 м/с;
- давление использует диапазон не уже 970…1040 гПа;
- влажность разделена на смысловые зоны;
- отмечаются переходы через 0 °C, морось, гроза и возможный туман.

## Согласованность версии

Единая проверка `scripts/check-version.py` сверяет:

- `pyproject.toml`;
- `VERSION`;
- `weather_to_docx.__version__`;
- метаданные адаптеров;
- User-Agent в конфигурациях;
- README и документы текущего выпуска;
- релизные маркеры.

Любое расхождение блокирует CI.

## Проверка

- Python 3.11, 3.12 и 3.13;
- Ruff и Pytest;
- тесты смысловых шкал и ансамблевых диапазонов;
- проверка wheel и автономного комплекта;
- рендер DOCX через LibreOffice и проверка PDF/PNG;
- контроль версии во всех активных источниках.

Полная история изменений находится в [`CHANGELOG.md`](../CHANGELOG.md).
