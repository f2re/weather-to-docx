# 🌦️ Weather to DOCX

`weather-to-docx` сравнивает прогнозы нескольких моделей и формирует оперативный документ Microsoft Word по каждой точке.

Текущая версия: **0.5.1**.

## Смысловые шкалы 0.5.1

Метеограмма больше не масштабирует каждую модель относительно её собственного максимума. Одинаковые величины выглядят одинаково на всех графиках.

### Осадки

Сумма за исходный интервал переводится в эквивалентную интенсивность:

```text
мм/ч = сумма осадков / длительность интервала
```

Поэтому:

```text
1 мм за 3 часа → 0,33 мм/ч
4 мм за 1 час  → 4 мм/ч
```

Ось осадков одинакова для всех моделей и ансамблей:

```text
0 · 0,5 · 2 · 5 · 10 · 12 мм/ч
```

Значения выше 12 мм/ч не растягивают весь график: столбик упирается в верх шкалы, рядом показывается фактическое значение.

Цветовые классы:

```text
следы
морось
слабые осадки
умеренные осадки
сильные осадки
ливень
```

Гроза получает отдельную фиолетовую обводку и подпись. Для каждого дня указывается:

- суточная сумма;
- характер осадков;
- длительность слабой мороси;
- отношение к единому оперативному ориентиру 10 мм/сут.

Ориентир 10 мм/сут не выдаётся за климатическую норму конкретной станции. Он нужен только для одинакового визуального сравнения всех графиков.

### Температура

Минимальный общий диапазон:

```text
−20…+40 °C
```

Если прогноз выходит за эти границы, ось расширяется. На всех графиках видны зоны:

- сильного мороза;
- мороза;
- перехода через 0 °C;
- жары;
- очень высокой температуры.

Точки перехода через 0 °C подписываются непосредственно на линии.

### Ветер и давление

Ветер использует общий диапазон не уже:

```text
0…25 м/с
```

Выделены уровни 5, 10, 14 и 20 м/с. Порывы от 14 м/с считаются сильными, от 20 м/с — опасными.

Давление использует шкалу не уже:

```text
970…1040 гПа
```

Поэтому небольшое изменение давления больше не выглядит как экстремальный скачок.

### Влажность

Панель влажности содержит зоны:

```text
сухо
нормально
влажно
очень влажно
```

Если одновременно наблюдаются высокая влажность, близость температуры к точке росы и слабый ветер, график показывает отметку о возможном тумане или дымке.

## Оперативная интерпретация

Первая страница отвечает на основные вопросы специалиста:

- какое явление существенно;
- когда оно начнётся и достигнет максимума;
- сколько моделей его подтверждают;
- какую вероятность показывает ансамбль;
- насколько уверенным считается сигнал.

События получают статус:

```text
Устойчивый сигнал
Вероятный сигнал
Отдельный сценарий
```

Одиночная модель не выдаётся за согласованный прогноз.

## Режимы документа

### Краткий

Сводка рисков, прогноз по дням, контрольные сроки и компактная ансамблевая таблица.

### Экспертный — по умолчанию

Краткая сводка и отдельная полноразмерная метеограмма каждой пригодной модели. Ансамбль получает самостоятельную страницу неопределённости.

### Полный

Экспертный режим плюс дополнительные модельные таблицы. Использует A3.

## Профессиональная метеограмма

Каждая метеограмма использует одну временную шкалу и пять панелей:

1. низкая, средняя и высокая облачность;
2. температура и точка росы;
3. относительная влажность;
4. интенсивность осадков и вероятности порогов;
5. ветер, порывы, направление ветра и давление.

Дополнительно показываются:

- ночь;
- направление ветра;
- минимум и максимум температуры;
- максимум осадков;
- грозовые интервалы;
- пороги сильных и опасных порывов;
- русские даты, единицы и подписи.

Для ансамбля используются медиана, диапазоны 25–75 и 10–90 процентов и вероятности превышения порогов.

## Контроль качества

После генерации проверяются:

- наличие крупных метеограмм в DOCX;
- русские дни недели;
- блок ключевых рисков;
- число страниц;
- пустые страницы;
- возможное касание содержимого края листа.

При наличии LibreOffice и Poppler DOCX преобразуется в PDF и проверяется физически.

## Быстрый запуск

```bash
git clone https://github.com/f2re/weather-to-docx.git
cd weather-to-docx
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
weather-to-docx init
```

API:

```bash
weather-to-docx-api
```

Worker:

```bash
weather-to-docx worker --poll-interval 5
```

Интерфейс:

```text
http://127.0.0.1:8080/
```

## Обновление установленной системы

Служба запускается из:

```text
/opt/weather-to-docx/current/venv
```

Обычный `git pull` не обновляет установленный пакет. Используйте:

```bash
cd /путь/к/weather-to-docx
git switch main
git pull --ff-only origin main
./scripts/update.sh
```

Проверка:

```bash
/opt/weather-to-docx/current/venv/bin/weather-to-docx --version
/opt/weather-to-docx/current/venv/bin/weather-to-docx-verify --deep
```

Ожидаемая версия:

```text
0.5.1
```

## Входные данные

Можно передать город, адрес, координаты, TXT, CSV, JSON или Telegram-геопозицию. Для каждой точки создаётся отдельный DOCX, для нескольких точек — общий ZIP.

DaData используется при наличии token. Без него применяется OpenStreetMap Nominatim. Часовой пояс определяется локально по координатам.

## Telegram

```text
/forecast  — сформировать прогноз
/cancel    — отменить активное задание
/sources   — показать модели
/settings  — настройки и состояние worker
/help      — помощь
```

Telegram и браузер используют общую SQLite-очередь.
