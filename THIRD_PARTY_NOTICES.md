# Сторонние компоненты и данные

Приложение использует сторонние библиотеки Python и системные компоненты. Полный перечень фиксируется в `wheelhouse` и SBOM релизного комплекта.

Основные компоненты:

- FastAPI;
- Uvicorn;
- Pydantic;
- httpx;
- python-docx;
- Pillow;
- cryptography;
- PyYAML;
- Typer;
- ECMWF ecCodes — при включённом прямом GRIB-адаптере.

Прогностические данные сохраняют собственные условия поставщиков. Система записывает поставщика, модель, источник и атрибуцию в метаданные и DOCX. Использование данных не меняет их исходную лицензию.
