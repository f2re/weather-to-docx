# Сторонние компоненты и данные

Приложение использует сторонние библиотеки Python и системные компоненты. Полный перечень версий, лицензий и контрольных сумм фиксируется в `wheelhouse` и SBOM релизного комплекта.

Основные компоненты:

- FastAPI;
- Starlette;
- Uvicorn;
- Pydantic и pydantic-settings;
- httpx;
- python-docx;
- Pillow;
- cryptography;
- python-telegram-bot;
- PyYAML;
- Typer;
- ECMWF ecCodes — при включённом прямом GRIB-адаптере.

Внешние сервисы:

- Telegram Bot API — канал приёма заданий и выдачи документов;
- DaData Suggestions API — интерактивное геокодирование;
- DaData Clean API — автоматическая стандартизация адресов при наличии secret key;
- Open-Meteo — доставка явно выбранных прогностических моделей;
- NOAA/NCEP NOMADS — прямые подмножества GFS GRIB2.

Прогностические данные сохраняют собственные условия поставщиков. Система записывает поставщика, модель, способ доставки, источник и атрибуцию в метаданные и DOCX. Использование данных не меняет исходную лицензию.

DaData token, DaData secret и Telegram bot token не входят в дистрибутив и должны задаваться владельцем установки.
